# Third-party assets

No third-party art, music, samples, fonts, or recordings are included. The icon, CSS illustration,
map tokens, and procedural tones are original project assets under MIT.

No font files are bundled. The interface names system-installed font families including Noto Sans
Arabic, Segoe UI, Tahoma, and Arial as fallbacks; this does not redistribute those fonts.

JavaScript dependencies are distributed by their respective authors under licenses recorded in
their packages and lockfile. They are build/runtime libraries rather than bundled attribution-required
creative assets. Any future attribution-required asset must list name, author, source, license,
modifications, and repository location here before merging.
