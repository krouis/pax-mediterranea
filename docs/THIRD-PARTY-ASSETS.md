# Third-party assets

No third-party art, music, samples, or recordings are included. The icon, CSS illustration, map
tokens, and procedural tones are original project assets under MIT.

The following fonts are bundled so offline text rendering and visual regression tests are stable:

| Name                          | Author | Source                                                | License                   | Modifications | Repository location                     |
| ----------------------------- | ------ | ----------------------------------------------------- | ------------------------- | ------------- | --------------------------------------- |
| Noto Sans Regular/Bold        | Google | [Noto fonts](https://github.com/notofonts/noto-fonts) | SIL Open Font License 1.1 | None          | `src/assets/fonts/NotoSans-*.ttf`       |
| Noto Sans Arabic Regular/Bold | Google | [Noto fonts](https://github.com/notofonts/noto-fonts) | SIL Open Font License 1.1 | None          | `src/assets/fonts/NotoSansArabic-*.ttf` |

The license and copyright notice are preserved in `src/assets/fonts/NOTO-LICENSE.txt`. The fonts
are redistributed under the OFL, independently of the project's MIT-licensed original work.

JavaScript dependencies are distributed by their respective authors under licenses recorded in
their packages and lockfile. They are build/runtime libraries rather than bundled attribution-required
creative assets. Any future attribution-required asset must list name, author, source, license,
modifications, and repository location here before merging.
