# Privacy

The static game sends no analytics, advertising, tracking pixels, fingerprints, cookies, or personal
information. Preferences and versioned save state remain in browser storage on the player's device.
Exported saves contain game data and selected display names only.

Optional online play is not required and is currently an adapter preview. A deployed transport may
temporarily process a sanitized display name, random room/player identifiers, presence, and game
actions for synchronization and reconnection. It must document retention, avoid open chat, limit
message size/rate, and never add analytics by default. Clearing site storage removes local data.
